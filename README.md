# Dual Threat

NCAA fantasy wrestling league site — standings, weekly matchups, rosters, and organizer tools.

## Live site

GitHub Pages (once enabled): https://warrinza.github.io/dual-threat/

## Local

Open `index.html` in a browser, or serve the folder with any static file server.

## Notes

- Organizer saves use Claude Artifacts when available; otherwise they fall back to this browser's localStorage (not shared across devices).
- Shared live league data would need a backend or committed data file later.
